# Sprint 4.4.1 Design Lab

This folder contains three original Flutter-rendered product directions using
sanitized compile-time fixtures. No reference-site assets, CSS, copy, logos,
screenshots, or animation files were downloaded or reused.

The supplied [Smart Fleet Saudi benchmark](https://smartfleetksa.com/) was
inspected only at page/content level after the concepts were rendered. It is a
public marketing and fleet-mediation surface; these concepts remain internal
operations workspaces with independent marks, names, palettes, compositions,
copy, maps, and interaction models.

## Concepts

- [A — Route Beacon / منارة المسار](concept-a-route-beacon.md)
- [B — Night Dispatch / غرفة الترحيل](concept-b-night-dispatch.md)
- [C — Field Ledger / سجل الميدان](concept-c-field-ledger.md)
- [Comparison and recommendation](comparison.md)
- [Local preview instructions](preview.md)

All 24 PNG files were captured from a real Chromium browser. Required evidence
includes Arabic/English 1440 dashboards, Arabic 390 Driver Today and My Truck,
and component/motion sheets. Additional 360, 768, and reduced-motion captures
prove the exploration remains structurally viable.

The source is an isolated Development entry point:
`apps/transport_management_app/lib/design_lab_main.dart`. Production
`main.dart`, routing, live features, API contracts, and retained data are
unchanged.
